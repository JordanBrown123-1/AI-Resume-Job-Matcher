📄 AI Resume & Job Matcher

A Python web application that analyzes resumes against job
descriptions using weighted skill matching and NLP.

[Live Demo]

📸 Screenshot

Features
• PDF resume parsing
• Required vs. preferred skill detection
• Weighted qualification scoring
• NLP similarity analysis
• Skill-gap detection
• Personalized resume recommendations
• Interview question generation
• Downloadable analysis reports
• Input validation and PDF error handling

Tech Stack
• Python
• Streamlit
• PyPDF
• scikit-learn
• TF-IDF
• Cosine Similarity

How It Works
Resume PDF
     ↓
Text Extraction
     ↓
Skill Detection & Normalization
     ↓
Required / Preferred Classification
     ↓
Weighted Match Score
     ↓
TF-IDF + Cosine Similarity
     ↓
Recommendations + Interview Questions
     ↓
Downloadable Report
